# Yanlis Kat Ozur Generatoru

> Asansorde yanlis butona basmak bir kaza degildir. Bir diplomasi krizidir.

Bu yazilim, dikey ulasim sucunun dogurdugu toplumsal gerilimi **uluslararasi protokol** seviyesinde yatistirmak icin yazilmistir. Calisir. Gercekten calisir. Python3 yeter.

## Neden bu kadar ciddi?

Cunku 4. katta inmesi gereken insan 11. katta indiğinde evrenin dengesinde milimetrik bir kayma olur. Biz o kaymayi mektupla duzeltiyoruz.

## Kurulum

```bash
python3 ozur.py
```

Baska bagimlilik yok. Pip yok. Docker yok. Sadece vicdan var.

## Ornek cikti

Program senden hedef kati sorar, sonra asiri resmi bir ozur mektubu basar. Istersen bos birak; kader (yani `random`) karar verir.

## Katkilarda bulunmak

Pull request acabilirsin ama once yanlis kata basilmis gibi ozur dile.

## Gizemli dipnot

Kodun icinde base64 bir satir vardir. O bir süs. Ciddiye alma. Ya da al. Farketmez.
